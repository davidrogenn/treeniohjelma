# treeniohjelma

* Käyttäjä pystyy luomaan tunnuksen ja kirjautumaan sisään sovellukseen.
* Käyttäjä pystyy lisäämään sovellukseen kuntosali-ohjelmansa treenitiedot, kuten käytetyt painot, liikkeet, toistot ja sarjat. Lisäksi käyttäjä pystyy muokkaamaan ja poistamaan lisäämiään tietoja.
* Käyttäjä näkee sovellukseen lisätyt tiedot. Käyttäjä näkee sekä itse lisäämänsä että muiden käyttäjien lisäämät tiedot halutessaan, ja näin pystyy seuraamaan kehitystään.
* Käyttäjä pystyy etsimään valmiiksi annettuja treeniliikkeitä hakusanalla, sekä itse lisämään niitä tarvittaessa.
* Sovelluksessa on käyttäjäsivut, jotka näyttävät jokaisesta käyttäjästä tilastoja ja käyttäjän lisäämät treenitiedot, sekä luokittelusijoituksen tehtyjen treenien määrästä ja prosentuaalisesta kehityksestä, joka edesauttaa treenaajien välistä kisailua esimerkiksi kavereiden kesken. 
* Treenitiedoille on valittavissa useampia luokitteluja (esim. yläkropan liikkeet, alakropan liikkeet, vapaa-paino, laitepainot).
* Käyttäjä pystyy lisämään kommentteja omiin ja muiden käyttäjien lisäämiin treeneihin, joiden avulla keskustelu treeneistä ja palautteen anto onnistuu.
